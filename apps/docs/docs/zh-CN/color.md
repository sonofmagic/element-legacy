## Color 色彩

Element 为了避免视觉传达差异，使用一套特定的调色板来规定颜色，为你所搭建的产品提供一致的外观视觉感受。

### 主色

Element 主要品牌颜色是鲜艳、友好的蓝色。

<color-doc-preview variant="main" />

### 辅助色

除了主色外的场景色，需要在不同的场景中使用（例如危险色表示危险的操作）。

<color-doc-preview variant="scene" />

### 中性色

中性色用于文本、背景和边框颜色。通过运用不同的中性色，来表现层次结构。

<color-doc-preview variant="neutral">
  <template #text-primary>主要文字</template>
  <template #text-regular>常规文字</template>
  <template #text-secondary>次要文字</template>
  <template #text-placeholder>占位文字</template>
  <template #border-base>一级边框</template>
  <template #border-light>二级边框</template>
  <template #border-lighter>三级边框</template>
  <template #border-extra-light>四级边框</template>
  <template #black>基础黑色</template>
  <template #white>基础白色</template>
  <template #transparent>透明</template>
</color-doc-preview>
