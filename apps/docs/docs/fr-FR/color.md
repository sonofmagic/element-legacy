## Couleur

Element utilise un ensemble de palettes spécifiques afin de fournir un style consistant pour vos produits.

### Couleur principale

La couleur principale d'Element est un bleu clair et agréable.

<color-doc-preview variant="main">
  <template #title>Couleur principale</template>
</color-doc-preview>

### Couleurs secondaires

En plus de la couleur principale, vous devrez sans doute utiliser d'autres couleurs pour différents cas de figures, par exemple une couleur de danger pour indiquer une opération dangereuse.

<color-doc-preview variant="scene">
  <template #success>Succès</template>
  <template #warning>Avertissement</template>
  <template #danger>Danger</template>
  <template #info>Info</template>
</color-doc-preview>

### Couleurs neutres

Les couleurs neutres sont les couleurs du fond, du texte et des bordures. Vous pouvez utiliser différentes couleurs neutres pour représenter une structure hiérarchique.

<color-doc-preview variant="neutral">
  <template #text-primary>Texte principal</template>
  <template #text-regular>Texte normal</template>
  <template #text-secondary>Texte secondaire</template>
  <template #text-placeholder>Texte de placeholder</template>
  <template #border-base>Bordure de base</template>
  <template #border-light>Bordure claire</template>
  <template #border-lighter>Bordure très claire</template>
  <template #border-extra-light>Bordure extra claire</template>
  <template #black>Noir</template>
  <template #white>Blanc</template>
  <template #transparent>Transparent</template>
</color-doc-preview>
